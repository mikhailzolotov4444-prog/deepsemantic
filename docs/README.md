# docs

- `PLAN.docx`: the original build plan ("Personal Teacher Website & Portfolio App: Build Plan").
  **Copy your original Word file here and name it `PLAN.docx`.** `CLAUDE.md` refers to it as
  the source of truth.
- `adr/`: Architecture Decision Records. One short file per important choice, numbered
  `NNNN-title.md`. Add one whenever a major dependency or design decision is made.

Deep Semantic (deepsemantic.ru): с чего начать

Это проект Phase 0 (фундамент). Сайт пока пустая заглушка. Подробная инструкция на английском лежит в файле README.md (его можно открыть любым текстовым редактором, например Блокнотом).

1. Распакуйте архив

Правый клик на deepsemantic-phase0.zip → «Извлечь всё». Дальше работаем внутри папки deepsemantic.

2. Установите три бесплатные программы (один раз)

  1. Node.js 22 LTS: https://nodejs.org
  2. Git: https://git-scm.com
  3. pnpm: откройте терминал (на Windows: PowerShell) и выполните corepack enable pnpm

3. Запустите проект

Откройте терминал внутри папки deepsemantic (на Windows: правый клик по пустому месту в папке → «Открыть в терминале») и выполняйте команды по порядку:

git init
pnpm install
pnpm format
pnpm check
pnpm dev
  • git init включает историю изменений (обязательно до pnpm install).
  • pnpm install скачивает библиотеки.
  • pnpm format один раз приводит файлы к единому виду.
  • pnpm check проверяет код. В конце всё должно быть без ошибок.
  • pnpm dev запускает сайт. Откройте http://localhost:3000 в браузере.

Если какая-то команда выдала ошибку, скопируйте весь текст ошибки и пришлите мне.

4. Положите свой план в проект

Скопируйте исходный Word-файл плана в папку docs и назовите его PLAN.docx.

5. Сохраните работу на GitHub

git add .
git commit -m "chore: phase 0 foundation"

Затем создайте пустой репозиторий на https://github.com и выполните две команды, которые GitHub покажет на странице репозитория. Файл pnpm-lock.yaml тоже нужно закоммитить, он нужен для автоматических проверок.

6. Что дальше

  • База данных (Neon или Supabase): понадобится с Phase 1, подробности в README.md.
  • Публикация на Vercel: тоже описана в README.md.
  • Важно: прочитайте docs/adr/0002-hosting-region-and-payments.md. Из-за домена .ru нужно решить, где хранить персональные данные посетителей и каким платёжным сервисом пользоваться (Stripe для России не подходит).

Когда pnpm check пройдёт без ошибок, напишите мне, и перейдём к Phase 1.
